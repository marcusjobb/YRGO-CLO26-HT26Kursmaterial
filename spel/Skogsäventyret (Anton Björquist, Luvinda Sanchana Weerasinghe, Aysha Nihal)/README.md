# Skogsaventyret

## Om projektet

Projektet baserar sig på Skogsäventyret och dess upplägg. Klasser, metoder och medlemsvariabler som enligt krav skall finnas med uppfylls. 
Spelaren får ange sitt namn och med med alternativ om hur dagens äventyr ser ut.

## Istallation 

```bash
git clone https://github.com/Aysha-Nihal/Skogsaventyret
cd ../Skogsaventyret
../Skogsaventyret/Skogsaventyret dotnet run
```

## Spelloop
Spelaren matar in sitt namn och presenteras med att trycka ENTER

Spelaren ges nu 5 olika val:
Utforska skogen
Vila sig i form
Ta sig till Arenan
Se sin stat
Avsluta spelet
