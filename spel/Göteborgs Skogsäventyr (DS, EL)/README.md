# Göteborgs Skogsäventyr

Grupp: DS, EL

## Så kör du

- Kör programmet med `dotnet run` i projektmappen (den som innehåller `.csproj`-filen).
- Öppna `index.html` i en webbläsare.

## Webbversion

Den grafiska versionen (`grafisk/Grafik`) är en webbsida. Gå till mappen `grafisk/Grafik`, kör `dotnet run` och öppna adressen som visas i terminalen.
