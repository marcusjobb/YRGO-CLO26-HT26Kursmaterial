# Schaktet Fängelse

Grupp: RT, MB

## Så kör du

- Kör programmet med `dotnet run` i projektmappen (den som innehåller `.csproj`-filen).
- Öppna `index.html` i en webbläsare.

## Webbversion

Öppna `index.html` i en webbläsare. Sidan hämtar typsnitt och three.js från nätet, så den kräver internetanslutning.
