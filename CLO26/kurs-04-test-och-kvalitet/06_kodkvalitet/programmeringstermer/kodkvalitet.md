# 06 Kodkvalitet — Programmeringstermer

## Statisk Kodanalys
Analys av källkod utan att köra programmet. Upptäcker potentiella buggar, kodlukt och säkerhetsproblem.

## Linting
Automatisk kontroll av kodstil och formatering. Exempel: ESLint (JS), StyleCop (C#).

## SonarQube
Plattform för kontinuerlig kodkvalitetsanalys. Ger betyg (A-E) på kodkvalitet och säkerhet.

## Säkerhetskopiering
Regelbunden backup av kod (Git) och data (databaser). 3-2-1-regeln: 3 kopior, 2 media, 1 off-site.

## CI/CD
Continuous Integration / Continuous Deployment. Automatiserad bygg-, test- och utlanseringskedja.

## Code Coverage
Mått på hur stor del av koden som täcks av automatiska tester. Vanliga verktyg: Coverlet, dotCover.

## Technical Debt
Kostnaden av att välja snabb lösning framför korrekt. Måste betalas tillbaka med tid eller omstrukturering.

## Code Smell
Ytlig indikation på djupare problem. Exempel: Switch-satser för typkontroll, tomma catch-block.

## Skyddad Mot SQL Injection
När kod använder parameterized queries istället för strängkonkatenering för att förhindra databasattacker.

## DevOps
Kultur och praxis som förenar utveckling (Dev) och drift (Ops). Automation, CI/CD, monitoring.
