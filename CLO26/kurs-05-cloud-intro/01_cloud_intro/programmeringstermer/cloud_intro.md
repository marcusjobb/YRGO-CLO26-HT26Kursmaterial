# 01 Cloud Intro — Programmeringstermer

## Cloud Computing
Tillhandahållande av datorkraft, lagring och applikationer över internet. Betala för vad du använder.

## IaaS
Infrastructure as a Service. Virtuella servrar, nätverk och lagring. Du hanterar OS och applikationer.

## PaaS
Platform as a Service. Hanterad plattform för att deploya appar. Du fokuserar på kod, inte server.

## SaaS
Software as a Service. Färdiga applikationer över internet. Exempel: Office 365, Google Workspace.

## Azure
Microsofts molnplattform. Erbjuder IaaS, PaaS, SaaS, AI-tjänster med mera.

## VM (Virtual Machine)
Programvarubaserad emulering av en fysisk dator. Kör ditt eget OS och dina appar.

## Skalbarhet
Systemets förmåga att hantera växande arbetsbelastning. Vertikal (större VM) vs horisontell (fler VM).

## Tillgänglighet
Andel tid ett system är operationellt. Uttrycks i procent (99.9% = tre nior).

## Region
Geografiskt område med Azure-datacenter. Välj region nära dina användare.

## Resursgrupp
Logisk container för Azure-resurser (VM, databaser, nätverk). Hanteras som en enhet.
