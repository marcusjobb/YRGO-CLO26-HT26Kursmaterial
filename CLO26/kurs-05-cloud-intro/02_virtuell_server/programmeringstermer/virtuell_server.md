# 02 Virtuell Server — Programmeringstermer

## Virtuell Server
En server som körs som en virtuell maskin i molnet. Full kontroll över OS och konfiguration.

## SSH
Secure Shell. Krypterat protokoll för att fjärransluta till en Linux-server. Port 22.

## RDP
Remote Desktop Protocol. Microsofts protokoll för att fjärransluta till Windows-servrar. Port 3389.

## PEM-nyckel
Privat nyckel (.pem-fil) som används för SSH-autentisering istället för lösenord.

## Public IP
Offentlig IP-adress som är nåbar från internet. En server kan ha en eller flera.

## Private IP
Intern IP-adress som bara är nåbar inom det virtuella nätverket.

## NSG
Network Security Group. Brandväggsregler som styr trafik till/från en VM i Azure.

## Image
Mall för att skapa en VM. Innehåller OS och förinstallerade applikationer.

## Snapshots
Ögonblicksbild av en VM-disk. Används för backup och återställning.

## Auto-shutdown
Funktion som automatiskt stänger ner en VM vid en schemalagd tid. Sparar pengar.
