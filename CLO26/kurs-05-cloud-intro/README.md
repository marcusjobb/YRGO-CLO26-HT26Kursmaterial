# Kurs 5 — Cloud-intro

En introduktion till molntjänster. Du lär dig vad IaaS, PaaS och SaaS är, hur de stora leverantörerna (Azure, AWS, GCP) skiljer sig åt — och du provisionerar en riktig server i molnet via terminalen.

## Moduler
| # | Modul | Vad du lär dig |
|---|-------|----------------|
| 01 | Cloud-intro | IaaS/PaaS/SaaS, molnleverantörer, grundkoncept |
| 02 | Virtuell server | Provisionera server via CLI, SSH, grundkonfiguration |
