# 04 Sql Avancerat — Programmeringstermer

## Subquery
SELECT inuti en annan SELECT. Används för komplex filtrering.

## CTE
Common Table Expression. Temporär namngiven resultatmängd: `WITH namn AS (SELECT ...)`

## Window Function
Funktion som beräknar över en grupp rader utan att gruppera dem: ROW_NUMBER, RANK, LAG.

## Stored Procedure
Sparad SQL-kod som kan återanvändas. Parametrar, logik, flera statements.

## Trigger
Automatisk exekvering vid INSERT/UPDATE/DELETE på en tabell.

## View
Sparad SELECT-sats som beter sig som en virtuell tabell. Förenklar komplexa frågor.

## Transaction
Grupp av SQL-operationer som behandlas som en enhet: COMMIT eller ROLLBACK.

## Index (advanced)
Databasstruktur för snabbare sökningar. Composite index, covering index, clustered vs non-clustered.

## Full-Text Search
Avancerad text-sökning med stemming, fritext, relevansrankning.

## ER Diagram
Entity Relationship Diagram. Visuell representation av tabeller och relationer.
