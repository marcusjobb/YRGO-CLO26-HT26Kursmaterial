# 05 Mongodb — Programmeringstermer

## MongoDB
Populär NoSQL-dokumentdatabas. Lagrar data som JSON-liknande dokument (BSON).

## Dokument
Grundläggande dataenhet i MongoDB. Motsvarar en rad i SQL men med flexibel struktur.

## Collection
Grupp av dokument i MongoDB. Motsvarar en tabell i SQL men schemalös.

## BSON
Binary JSON. MongoDBs binära format för dokumentlagring. Snabbare och mer datatyper än JSON.

## ObjectId
Unik 12-byte identifierare som MongoDB genererar för varje dokument.

## Aggregation Pipeline
MongoDBs ramverk för databehandling: match → group → sort → project.

## Index (MongoDB)
Förbättrar sökprestanda. MongoDB har inbyggt index på _id. Skapa index ofta använda fält.

## Replica Set
MongoDBs replikeringsmekanism. En primär och flera sekundära noder för hög tillgänglighet.

## Sharding
Horisontell skalning i MongoDB. Data distribueras över flera servrar baserat på en shard-nyckel.

## NoSQL
Icke-relationell databas. Fyra typer: dokument (MongoDB), key-value (Redis), column (Cassandra), graph (Neo4j).
