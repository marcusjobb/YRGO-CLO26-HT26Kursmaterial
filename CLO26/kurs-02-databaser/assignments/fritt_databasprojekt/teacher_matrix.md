# Bedömningsmatris – Fritt databasprojekt

## G (Godkänt)

| Kriterium | Godkänt | Underkänt |
|-----------|---------|-----------|
| Databasdesign | ≥3 tabeller/collections med logiska relationer, normaliserad | För få tabeller, inga relationer, denormaliserad |
| CRUD | Full CRUD för alla tabeller (Skapa, Läsa, Uppdatera, Radera) | Saknar CRUD-operationer |
| Användargränssnitt | Fungerande meny/GUI, användaren kan navigera och utföra alla operationer | Otydlig eller trasig navigering |
| Felhantering | try-catch för användarinput och databasfel | Kraschar vid felaktig inmatning |
| README | Projektbeskrivning, screenshots (≥2), installationsinstruktioner | Saknar README eller är ofullständig |
| Kodstruktur | Tydlig klassindelning, SRP, meningsfulla namn, inga varningar | Allt i en fil, otydlig kod |

## VG (Väl Godkänt)

| Kriterium | Godkänt | Underkänt |
|-----------|---------|-----------|
| VG-funktioner | Minst 2 VG-funktioner implementerade | Färre än 2 |
| Kodkvalitet | Interface, DI, clean architecture | Spagettikod |
| Reflektion | Djupgående svar med konkreta exempel | Ytliga svar |
