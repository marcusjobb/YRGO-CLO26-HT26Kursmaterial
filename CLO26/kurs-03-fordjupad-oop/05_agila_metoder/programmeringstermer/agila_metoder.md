# 05 Agila Metoder — Programmeringstermer

## Agil Metod
Iterativ och inkrementell utvecklingsmetod där krav och lösningar utvecklas genom samarbete.

## Scrum
Agilt ramverk med sprintar (2-4 veckor), daily standups, sprint review och retrospective.

## Sprint
Tidsbegränsad iteration (ofta 2 veckor) där ett potentiellt levererbart produktinkrement skapas.

## Product Backlog
Prioriterad lista av krav, funktioner och förbättringar som ska implementeras.

## Sprint Backlog
Uppsättning av backlog-objekt som teamet åtar sig att slutföra under en sprint.

## Daily Standup
Kort dagligt möte (15 min) där teamet synkar: vad gjorde igår, vad ska göras idag, vad blockerar.

## Retrospective
Möte i slutet av varje sprint där teamet reflekterar över vad som fungerade och vad som kan förbättras.

## Kanban
Agil metod med visuellt flöde (kanban-tavla) och WIP-gränser för att optimera genomflöde.

## User Story
Kort beskrivning av en funktion ur användarens perspektiv: Som [roll] vill jag [mål] för att [nytta].

## Definition of Done
Gemensam överenskommelse om vad som krävs för att ett arbetsstycke ska anses klart.
