# Skapa en databas med Entity Framework Code First

I denna uppgift ska du skapa ett program som håller koll på patienter på ett djursjukhus.

Databasen ska hålla koll på djur och deras ägare

- Skapa en databas (SQL-Server eller SQLite)

- Skapa tabeller för djur och ägare

- Skapa testinformation i tabellen (minst ett djur och 1 ägare)

- Köra CRUD mot din persontabell

- Create – Skapa en person i databasen

- Read –

- Lista upp alla personer och deras djur i bokstavsordning

- Söka efter personer

- Update - Uppdatera personen

- Delete – Ta bort en person ur listan

- Köra CRUD mot din djurtabell

- Create – Skapa ett djur i databasen

- Read –

- Lista upp alla djur i bokstavsordning

- Söka efter djur

- Update - Uppdatera djuret

- Delete – Ta bort en djuret ur listan

- Allt ska göras ifrån C#

- Dela upp koden i

- Controllers (som kommunicerar med databasen)

- View (som visar information)

- Databasen skapas av Entity Framerwork, så det ska räcka med att köra update-database

- När programmet körs första gången ska den skapa testdata

- Den ska visa upp resultatet av på consolen

- Fråga användaren om ett namn på en person och visa vilka djur personen äger

- Fråga användaren om ett namn på ett djur och visa djuret
