# Modul 2 — Syntax och variabler

**Tema:** Variabler, datatyper, strängar, aritmetik
**Inlämning:** Ingen inlämning

## Vad du ska kunna när modulen är klar

- Deklarera och använda variabler i C#
- Förstå och välja rätt datatyp: `int`, `double`, `string`, `bool`
- Använda string interpolation för att bygga upp text
- Räkna med aritmetiska operatorer (`+`, `-`, `*`, `/`, `%`)
