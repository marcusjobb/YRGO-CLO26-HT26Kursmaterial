# Vecka 1 — Kursplan
*Verktyg, Git och Git Bash*
*Ingen inlämning*

---

## Mål för veckan

När veckan är slut ska alla studerande:

- [ ] Ha Git installerat och konfigurerat (namn + email)
- [ ] Kunna använda Git Bash som terminal
- [ ] Ha IDE installerad (VS Community eller Rider)
- [ ] Ha .NET SDK 10 installerat (`dotnet --version` fungerar)
- [ ] Ha VS Code installerat
- [ ] Ha ett GitHub-konto
- [ ] Kunna klona ett repo, göra en ändring, commit och push
