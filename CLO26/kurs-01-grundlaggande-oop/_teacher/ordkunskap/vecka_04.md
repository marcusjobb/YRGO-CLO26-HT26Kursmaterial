# Ordkunskap — Vecka 4
*Datastrukturer och samlingar*

---

## Ord att fördela på grupper

### Grupp A
- **Array** — en lista med fast längd, indexeras från 0
- **Lista (List\<T\>)** — en dynamisk samling som växer och krymper

### Grupp B
- **Dictionary** — nyckel/värde-par (som ett uppslagsverk)
- **Index** — positionen för ett element i en samling (börjar på 0)

### Grupp C
- **Stack** — LIFO: sist in, först ut (som en tallriksbunt)
- **Queue** — FIFO: först in, först ut (som en kö)

### Grupp D
- **Iteration** — att gå igenom en samling element för element
- **LINQ** — Language Integrated Query, fråga samlingar som en databas

### Grupp E
- **Algoritm** — en steg-för-steg-lösning på ett problem
- **Tidskomplexitet / Big O** — hur snabbt en algoritm växer när datamängden växer

### Grupp F
- **Sorteringsalgoritm** — algoritm för att ordna element (bubble sort, merge sort...)
- **Binärsökning** — sök i sorterad lista genom att halvera vid varje steg
