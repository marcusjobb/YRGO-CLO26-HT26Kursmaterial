## Ord att fördela på grupper

Varje grupp får 2–3 ord. Anpassa antal grupper efter klasstorlek.

### Grupp A
- **Frontend** — det som syns i webbläsaren / det användaren interagerar med
- **Backend** — servern, logiken, databasen bakom kulisserna

### Grupp B
- **API** — ett gränssnitt för att prata med ett system (som ett uttag i väggen)
- **REST** — ett sätt att bygga API:er (vanligaste sättet på webben)

### Grupp C
- **Server** — en dator (eller program) som svarar på förfrågningar
- **Klient** — den som ställer frågan (webbläsare, app, annat program)

### Grupp D
- **Databas** — organiserad lagring av data
- **Repository / Repo** — ett versionshanterat projekt (din kodhink med historik)

### Grupp E
- **Deploy / Driftsättning** — att publicera kod så att riktiga användare kan använda den
- **Debug / Felsökning** — hitta och fixa fel i koden

### Grupp F
- **Framework** — ett färdigt skelett man bygger sin applikation ovanpå
- **IDE** — utvecklingsmiljö (Visual Studio, Rider, VS Code)

### Extra (om stor klass)
- **Kompilator** — program som översätter din kod till maskinspråk
- **Runtime** — miljön där koden körs (CLR för .NET)
- **Versionshantering** — spåra ändringar i kod över tid (Git)
- **Cloud / Molnet** — datorer och tjänster som nås via internet
