# Ordkunskapspresentationer — kurs-01

## Format

**Tid:** 5 minuter per grupp  
**När:** Dag 2 varje vecka (studerande fick orden dag 1)  
**Vecka 1:** Inga presentationer  
**Vecka 2–5:** En grupp per ord, 2–3 ord per grupp

## Upplägg

Varje grupp förklarar sina ord för klassen:
1. **Vad är det?** — Förklara med egna ord, inte Wikipedia
2. **Var används det?** — Ge ett verkligt exempel
3. **Visa eller rita** — Whiteboard, skiss, kodrad, whatever

Resten av klassen: en fråga per ord.
