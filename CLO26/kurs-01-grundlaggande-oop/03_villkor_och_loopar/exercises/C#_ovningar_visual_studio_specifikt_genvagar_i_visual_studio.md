Genvägar i Visual Studio
Det finns en del trevliga genvägar i Visual Studio som gör kodandet väldigt mycket enklare.
Här är några av mina favoriter.
Shortcut
ALT Up/Down

Funktion
ALT plus pil upp eller ner flyttar hela raden upp eller ner

CTRL -

Control minus skickar en tillbaka från dit man hoppat med F12

CTRL .

Visar meny med snabbfunktioner och refactoringförslag

CTRL k d

Städar upp dokumentet om den inte är rätt tabulerad

CTRL C

Copy som vanligt

CTRL F5

Kör utan debug

CTRL K S

Visa ”Surround with” menyn

CTRL SHIFT F12

Hoppa till nästa error i koden

CTRL V

Klistar in som vanligt

CTRL W E

Visa errorlistan

CTRL W O

Visa outputfönstret

CTRL W T

Visa //TODO: listan

CTRL X

Klipper ut som vanligt

F10

Stega över metod vid debugging

F11

Stega in i metod vid debugging

F12

F5

Om man ställer pekaren på en metod kommer F12 att skicka en till metodens
definition
När man pekar på en class, metod eller variabel kan man använda F2 för att byta
namn på den överallt.
Kör med debug

F9

Skapa eller ta bort breakpoint

F2

Shift Alt Enter

Växla fullskärmsläge

SHIFT ALT l j

Sammanfoga rader
