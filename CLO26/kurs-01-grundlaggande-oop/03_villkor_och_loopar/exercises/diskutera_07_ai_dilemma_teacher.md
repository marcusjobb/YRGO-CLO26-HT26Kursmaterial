## Faciliteringsguide

Det här är vibe coding-dilemmat i ett nötskal. AI genererar kod som "fungerar" men som ingen förstår. Ingen ifrågasätter. Det går snabbt. Tills det inte gör det.

**Poänger att lyfta:**
- Du äger koden du pushar, oavsett var den kommer ifrån
- "Det fungerar" ≠ "Det är korrekt" ≠ "Det är säkert"
- Code review förutsätter att granskaren förstår vad de granskar
- Säkerhetskritisk kod kräver expertis — inte bara fungerande syntax

**Forskning att lyfta:**
- En studie från Stanford (2022) visade att GitHub Copilot-genererad kod innehöll säkerhetsproblem i ~40 % av fallen i säkerhetskritiska scenarion
  *(Pearce et al., 2022. Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions)*

**Bra fråga:** "Vad skiljer en senior som använder AI bra från en senior som använder AI dåligt?"

**Kopplar till:** AI-kodning, code review, teknisk skuld, säkerhet, professionellt ansvar.
Och varför kursen lär er förstå koden — inte bara producera den.
