Använd Git och GitHub för att verisionshantera VS projektet.
Använd try/catch statements för att hantera minst ett undantag.
Skriv tester för att testa minst en del av din lösning.
Använd dig av Math/IO/DateTime/Random klasserna och datastrukturer såsom
List/Dictionary där lämpligt.
Lämna in en rapport som beskriver hur du bröt ner problemet i mindre delar, hur du valde
att testa ditt program och lite motivation kring några .Net Core klasser du valde att använda.

Rapport format: block comment/.txt/README/pdf
Nedan har jag skrivit lite förslag, men om du har en bättre idé så får du gärna göra det istället.
Bara kolla med mig så jag kan ge feedback så det inte blir för svårt/lätt. Annars är det fritt fram
förutom att du håller dig till G kraven ovan.
