# 07 Git Och Markdown — Programmeringstermer

## Git
Distribuerat versionshanteringssystem. Spårar ändringar i källkod över tid och möjliggör samarbete.

## Repository
Git-databas som innehåller alla filer och deras ändringshistorik.

## Commit
Ögonblicksbild av förändringar i Git. Varje commit har ett unikt hash-id och ett meddelande.

## Branch
Parallel version av koden. Main/master är standardbranchen. Feature-branches för ny utveckling.

## Merge
Slå ihop ändringar från en branch till en annan. Kan orsaka merge-konflikter.

## Pull Request
Begäran att mergea en branch till en annan (ofta till main). Kodgranskning innan merge.

## Push/Pull
Pusha = skicka commits till remote. Pull = hämta commits från remote.

## Clone
Skapa en lokal kopia av ett remote repository.

## Markdown
Lättviktigt märkspråk för formatering av text. Används i README, dokumentation, kommentarer.

## GitHub
Molnbaserad Git-tjänst med PRs, issues, Actions, wikis.

## .gitignore
Fil som anger vilka filer/mappar Git ska ignorera. Exempel: `bin/`, `obj/`, `.env`.

## Fork
Egen kopia av ett annat repository på GitHub. Ändringar kan föreslås via PR.
