Git övningar
1. Skapa ett nytt repo på Github
2. Skapa ett lokalt repo på din dator med samma namn. ex git init
3. Skapa en tom README.md fil.
4. Använd git status för att se alla aktiva ändringar.
5. Använd git add för att lägga till README.md filen i ditt repo.
6. Använd git commit för att commita ändringarna. ex git commit -m "example commit"
7. Koppla ihop ditt lokala repo med ditt Github repo genom att använda git remote add origin
kommandet.
8. Pusha din commit till github.
9. Gå till github och ändra på README.md file (ex en introduktion till repot). Glöm inte att trycka på
"commit changes" knappen.
Nu är ditt lokala repo och github repo i osynk. Github repot har fler ändringar än ditt lokala.
10. Använd git pull för att hämta dessa ändringar
