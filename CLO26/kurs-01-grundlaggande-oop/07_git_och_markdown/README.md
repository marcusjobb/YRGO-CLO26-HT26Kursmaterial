# Modul 7 — Git fördjupning och Markdown

**Tema:** Git-flöde, konflikter, Markdown-syntax

> Git-kunskaper examineras löpande — i Skogsäventyret och via alla inlämningar.

## Vad du ska kunna när modulen är klar

- Hantera en merge conflict — förstå vad som hänt och lösa den
- Förstå Git-flöde med branches: skapa, byta, slå ihop
- Skriva välstrukturerad Markdown med rubriker, listor, tabeller och kodblock
- Skriva en README.md som faktiskt är till hjälp för den som läser den
