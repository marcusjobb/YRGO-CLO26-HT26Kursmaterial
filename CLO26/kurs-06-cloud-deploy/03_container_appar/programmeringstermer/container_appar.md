# 03 Container Appar — Programmeringstermer

## Container App
Hanterad plattform i Azure för att köra containeriserade applikationer utan att hantera orkestrator.

## Revisions
Versioner av en container app. Varje deployment skapar en ny revision.

## Ingress
Azure Container Apps ingress-konfiguration. Hanterar HTTPS, TLS och trafikstyrning.

## Scaling
Container Apps kan skalas automatiskt baserat på HTTP-trafik, CPU eller event.

## Dapr
Distributed Application Runtime. Byggstenar för mikroservices: state management, pub/sub, service invocation.

## Environment Variables
Konfiguration injicerad i containern. Hanteras via Azure Portal eller ARM/Bicep.

## Ingress Restriction
Begränsningar för vilken trafik som når containern. IP-vitlistning, autentisering.

## GitHub Container Registry (GHCR)
GitHubs registry för container-images. Integrerat med GitHub Actions.

## Azure Container Registry (ACR)
Microsofts privata registry för container-images. Används av Azure Container Apps.

## KEDA
Kubernetes Event-driven Autoscaling. Används av Container Apps för att skala baserat på meddelandeköer, databas mm.
