# 06 Datalagring I Moln — Programmeringstermer

## Blob Storage
Azure-lagring för ostrukturerad data (bilder, videor, dokument). Tre tier: Hot, Cool, Archive.

## Azure SQL Database
Hanterad relationsdatabas i Azure. SQL Server-kompatibel. Inbyggd backup, HA, skalning.

## Cosmos DB
Azure's NoSQL-databas. Multi-model: document, key-value, graph, column-family.

## Azure Redis
Hanterad Redis-cache i Azure. Används för session state, output caching, real-time data.

## Storage Account
Azure-konto för lagring. Innehåller blobs, files, queues, tables.

## Connection String (Storage)
"DefaultEndpointsProtocol=https;AccountName=minkonto;AccountKey=...;EndpointSuffix=core.windows.net"

## Geo-redundans
Automatisk replikering av data till annan Azure-region. Skyddar mot regionala fel.

## SAS Token
Shared Access Signature. Tidsbegränsad åtkomstnyckel till specifik blob/container.

## CDN
Content Delivery Network. Cachar innehåll på edge-servrar globalt för snabbare leverans.

## Azure Files
Hanterad SMB-filshare i Azure. Kan mountas som nätverksenhet på flera VM.
