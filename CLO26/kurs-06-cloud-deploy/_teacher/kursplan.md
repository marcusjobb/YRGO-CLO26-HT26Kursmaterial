# Kurs 6 — Cloud-deploy

**YH-poäng:** 40 | **Längd:** 8 veckor

## Kursbeskrivning
Kursen täcker hela flödet från källkod till produktionssatt molntjänst. Studerande bygger CI/CD-pipelines, paketerar applikationer i Docker-containers och driftsätter dem i molnet. Kursen avslutas med ett projekt där studerande kombinerar alla moment: pipeline, container, webbapp med autentisering och molnlagring.

## Lärandemål
- Kunna bygga och konfigurera en CI/CD-pipeline (GitHub Actions eller Azure DevOps)
- Förstå och använda Docker: images, containers, Dockerfile och docker-compose
- Kunna driftsätta en containerbaserad webbapplikation i molnet
- Kunna implementera autentisering och auktorisering med etablerade molntjänster
- Förstå hur data lagras och hämtas från molnbaserade lagringstjänster
- Kunna planera och genomföra ett litet molndriftsättningsprojekt självständigt

## Modulöversikt
| Modul | Innehåll |
|-------|----------|
| 01 | CI/CD — GitHub Actions, pipelines, automatiserad testning och deployment |
| 02 | Docker — containers, images, Dockerfile, docker-compose |
| 03 | Container-appar — driftsätta containers i molnet, environment variables, secrets |
| 04 | Webbapplikationer — REST API i molnet, webb-frontend, HTTP och HTTPS |
| 05 | Auth och identitet — OAuth2, JWT, Azure AD / Cognito, roller och claims |
| 06 | Datalagring i molnet — Blob Storage, databaser som tjänst, backup och återställning |
| 07 | Projekt — självständigt projekt som kombinerar alla moduler |

## Examination
Projekt i vecka 7 är en inlämningsuppgift som examinerar alla lärandemål. Betyg: G eller VG.
