# Kurs 6 — Cloud-deploy

Från källkod till produktionssatt molntjänst. Du bygger pipelines, lär dig Docker och driftsätter containers — och i projektveckan sätter du ihop allt på riktigt.

## Moduler
| # | Modul | Vad du lär dig |
|---|-------|----------------|
| 01 | CI/CD | GitHub Actions, automatiserade pipelines, testning och deploy |
| 02 | Docker | Images, containers, Dockerfile och docker-compose |
| 03 | Container-appar | Driftsätta containers i molnet, secrets, environment vars |
| 04 | Webbapplikationer | REST API, webb-frontend, HTTP/HTTPS i molnmiljö |
| 05 | Auth och identitet | OAuth2, JWT, rollbaserad åtkomstkontroll |
| 06 | Datalagring i molnet | Blob Storage, DBaaS, backup |
| 07 | Projekt | Självständigt projekt — allt tillsammans |

## Hur du arbetar med materialet
- Börja med att läsa `README.md` i varje modul
- Titta igenom föreläsningsslides i `lectures/`
- Fördjupa dig med läsning i `notes/`
- Gör övningarna i `exercises/`
- Lämna in via Google Classroom
