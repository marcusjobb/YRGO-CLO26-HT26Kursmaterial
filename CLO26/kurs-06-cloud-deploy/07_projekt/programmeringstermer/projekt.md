# 07 Projekt — Programmeringstermer

## Projektplan
Dokument som beskriver projektets mål, omfattning, tidsplan, resurser och risker.

## Tidsplan
Plan över projektets aktiviteter med start- och slutdatum. Gantt-schema eller sprintar.

## Milestone
Viktig hållpunkt i projektet. Exempel: första deployment, feature-freeze, release.

## Riskhantering
Identifiera, analysera och hantera risker i projektet. Sannolikhet × konsekvens.

## Acceptanstest
Test som verifierar att systemet uppfyller kundens krav och kan godkännas.

## Dokumentation
Systembeskrivning, arkitektur, API-dokumentation, deploy-instruktioner.

## Release
Version av systemet som lanseras till produktion. Bör vara märkt med version (semver).

## Retrospective (projekt)
Utvärdering efter projektet. Vad fungerade? Vad kan förbättras? Vad tar vi med oss?

## Stretch Goal
Extra mål som vi försöker nå om tid finns. Prioriteras efter huvudkraven.

## MVP
Minimum Viable Product. Den minsta fungerande versionen som levererar kundvärde.
