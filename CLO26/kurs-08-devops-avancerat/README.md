# Kurs 8 — DevOps-avancerat

DevOps på djupet. Infrastruktur som kod, avancerade deployment-strategier, monitorering och nätverkssäkerhet — du arbetar som en erfaren DevOps-ingenjör.

## Moduler
| # | Modul | Vad du lär dig |
|---|-------|----------------|
| 01 | IaC | Terraform, Bicep, ARM — infrastruktur som kod |
| 02 | CI/CD avancerat | Blue-green, canary, rollback-strategier |
| 03 | Monitorering | Application Insights, Prometheus, Grafana, alerting |
| 04 | Säkerhet och nätverk | NSG, brandväggar, VPN, Key Vault |
| 05 | Containerarkitektur | Service mesh, microservices, sidecar-mönster |
| 06 | Projekt | Självständigt projekt — allt tillsammans |

## Hur du arbetar med materialet
- Börja med att läsa `README.md` i varje modul
- Titta igenom föreläsningsslides i `lectures/`
- Fördjupa dig med läsning i `notes/`
- Gör övningarna i `exercises/`
- Lämna in via Google Classroom
