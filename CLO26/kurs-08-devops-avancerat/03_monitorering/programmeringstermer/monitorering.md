# 03 Monitorering — Programmeringstermer

## Monitorering
Övervakning av systemhälsa, prestanda och tillgänglighet. Upptäcka och åtgärda problem tidigt.

## Application Insights
Azure-tjänst för applikationsmonitorering. Spårar requests, exceptions, dependencies, traces.

## Log Analytics
Azure-tjänst för central loggning. KQL (Kusto Query Language) för att söka och analysera loggar.

## Metric
Numeriskt mått över tid: CPU-användning, request rate, svarstid. Kan trigga larm.

## Alert
Automatisk notifiering när en metric passerar en tröskel. Skicka email, SMS, eller trigga en Azure Function.

## Dashboard
Visualisering av metrics och loggar. Sammanfattning av systemhälsa på en skärm.

## Distributed Tracing
Spåra en request genom flera tjänster (mikroservices). Identifiera flaskhalsar i kedjan.

## KQL
Kusto Query Language. Azure Monitor-språk för att fråga loggar och metrics.

## SLA Monitoring
Övervakning av faktisk tillgänglighet mot avtalad SLA. Upptäck om du riskerar att bryta avtalet.

## Runbook
Dokumenterad procedur för att hantera kända problem. Minska MTTR (Mean Time To Resolve).
