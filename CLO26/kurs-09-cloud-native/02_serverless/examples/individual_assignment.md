# Individuell inlämningsuppgift i Molnbaserad Integration

🟢


## Syfte

Denna uppgift syftar till att visa att du kan drifta och integrera en molnbaserad lösning med en befintlig lösning.

## Uppgift

- Använd den källkod som gruppen skapat under kursens gång (forka repot).
- Skapa en molnbaserad integration mellan en befintlig lösning och en ny lösning.
- Det kan tex vara att:
  - hämtar väderdata från en extern tjänst och visar det snyggt formaterat i en utläsbar sträng.
  - skickar någon data för behandling av ChatGPT/Clade m.fl.
- Använd Azure DevOps för att bygga och distribuera lösningen.
- Använd Azure Monitor för att övervaka lösningen.

## Krav

### Godkänt

- Du ska använda Azure DevOps för att bygga och distribuera lösningen.
- Kunna skapa hela lösningen manuellt i Azure Portal.
- Förbered en 5 minuters presentation som visar hur du har löst uppgiften.

## Väl godkänt

**Utöver Godkänt krav, ska du även:**

- Skapa delar eller hela lösningen med Azure CLI.
