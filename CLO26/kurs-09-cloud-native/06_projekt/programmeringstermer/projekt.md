# 06 Projekt — Programmeringstermer

## Cloud Native Projekt
Slutprojekt som tillämpar cloud-native principer: containerisering, CI/CD, skalning, monitorering.

## Arkitekturgenomgång
Presentation av din arkitektur med motiveringar. Förbered svar på 'Varför valde du X?'

## Kostnadsanalys
Beräkning och optimering av molnkostnader. Reserved instances, auto-scaling, rätt sizing.

## Well-Architected Framework
Microsofts ramverk för molnarkitektur: Cost Optimization, Operational Excellence, Performance, Reliability, Security.

## Trade-off Analysis
Analys av avvägningar mellan alternativ. Kostnad vs prestanda, enkelhet vs flexibilitet.

## Tech Stack Documentation
Dokumentation av teknologival: språk, ramverk, databaser, CI/CD, monitorering.

## Deployment Diagram
Visuell representation av hur systemet deployas: VM, containrar, nätverk, DNS.

## Capacity Planning
Planering av resursbehov baserat på förväntad belastning. Använd load testing.

## Go/No-Go
Beslutspunkt: är systemet redo att lanseras? Kriterier: alla kritiska tester passerade, inga blockerande buggar.

## Post-Launch Review
Utvärdering efter lansering. Mät mot mål. Vad fungerade? Vad kan förbättras?
