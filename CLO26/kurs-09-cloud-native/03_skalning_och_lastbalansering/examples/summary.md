# Kurssammanfattning för Molnintegration

🟢


Detta är en 50-poängs kurs i "Molnintegration (10v)" som fokuserar på att lära ut:

1. **Azure molnfundament och infrastruktur**
   - Migrera från manuell serverdrift till molnbaserad automation
   - Azure Virtual Machines, Resource Groups och kostnadsstyrning
   - Azure CLI och Infrastructure as Code med ARM/Bicep templates
   - Containerisering med Azure Container Registry och Azure Kubernetes Service
   - Säkerhet genom Azure Active Directory och Key Vault

2. **Integration och meddelandehantering**
   - Azure Service Bus för asynkron kommunikation och köhantering
   - Event-driven arkitektur med Azure Event Grid
   - Azure API Management för enterprise-skalig API-hantering
   - Logic Apps för visuella integration workflows
   - Mikrotjänstarkitektur och inter-service kommunikation

3. **DevOps och automation**
   - CI/CD pipelines med Azure DevOps och GitHub Actions
   - Blue-green och canary deployment-strategier
   - Monitoring och observability med Azure Monitor och Application Insights
   - Automated testing och Infrastructure as Code automation
   - Performance optimization och intelligent alerting

4. **Säkerhet och regelefterlevnad**
   - GDPR-implementering i molnmiljöer och data protection
   - Network security med Virtual Networks och Azure Firewall
   - Secrets management och certificate handling
   - Multi-cloud strategier och vendor lock-in undvikande
   - AWS-jämförelse och framtidsperspektiv inom molnintegration

Kursen använder en hands-on pedagogisk approach där studenter först upplever manuella processer för att sedan förstå molnautomationens värde. Examination sker genom 100% skriftligt prov som täcker både teoretiska koncept och praktiska tillämpningar.
