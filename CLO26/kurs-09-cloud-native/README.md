# Kurs 9 — Cloud-native

Modern cloud-native arkitektur och drift. Du arbetar med Continuous Delivery, serverless, auto-skalning och skriptautomation — och designar system som håller under riktiga produktionsförhållanden.

## Moduler
| # | Modul | Vad du lär dig |
|---|-------|----------------|
| 01 | Continuous Delivery | Deployment-gates, feature flags, automatiserat rollout |
| 02 | Serverless | Azure Functions, AWS Lambda, event-driven arkitektur |
| 03 | Skalning och lastbalansering | Horisontell skalning, load balancer, auto-scaling |
| 04 | Automation Bash/PowerShell | Skriptautomation för drift och deployment |
| 05 | Arkitekturmönster | CQRS, event sourcing, strangler fig, saga-mönstret |
| 06 | Projekt | Självständigt cloud-native projekt |

## Hur du arbetar med materialet
- Börja med att läsa `README.md` i varje modul
- Titta igenom föreläsningsslides i `lectures/`
- Fördjupa dig med läsning i `notes/`
- Gör övningarna i `exercises/`
- Lämna in via Google Classroom
