# Kurs 9 — Cloud-native

**YH-poäng:** 40 | **Längd:** 8 veckor

## Kursbeskrivning
Kursen tar ett cloud-native perspektiv på modern mjukvaruutveckling och drift. Studerande lär sig Continuous Delivery och Deployment, serverless-arkitektur med Azure Functions och AWS Lambda, horisontell skalning och lastbalansering, skriptautomation med Bash och PowerShell samt etablerade arkitekturmönster för distribuerade system.

## Lärandemål
- Kunna konfigurera och driftsätta en Continuous Delivery-pipeline med automatiska deployment-gates
- Förstå och implementera serverless-funktioner med Azure Functions eller AWS Lambda
- Kunna konfigurera horisontell skalning och lastbalansering för en webbapplikation
- Skriva automation-scripts i Bash och PowerShell för vanliga driftsuppgifter
- Kunna identifiera och tillämpa lämpliga arkitekturmönster för distribuerade system
- Kunna planera och genomföra ett cloud-native projekt självständigt

## Modulöversikt
| Modul | Innehåll |
|-------|----------|
| 01 | Continuous Delivery — deployment-gates, feature flags, automatiserat rollout |
| 02 | Serverless — Azure Functions, AWS Lambda, event-driven arkitektur |
| 03 | Skalning och lastbalansering — horisontell skalning, load balancer, auto-scaling |
| 04 | Automation Bash/PowerShell — skriptautomation för drift och deployment |
| 05 | Arkitekturmönster — CQRS, event sourcing, strangler fig, saga-mönstret |
| 06 | Projekt — självständigt cloud-native projekt |

## Examination
Projekt i vecka 6 är en inlämningsuppgift som examinerar alla lärandemål. Betyg: G eller VG.
