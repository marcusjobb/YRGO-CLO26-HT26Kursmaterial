# Avslut och rapport

## Deadline
Rapporten lämnas in via Google Classroom senast sista fredagen i LIA-perioden.

## Rapportstruktur
1. **Inledning** — Beskriv arbetsplatsen, din roll och dina arbetsuppgifter
2. **Tekniskt innehåll** — Vilka tekniker och verktyg använde du? Ge konkreta exempel.
3. **Yrkesmässig utveckling** — Vad lärde du dig? Vad var svårt? Vad är du stolt över?
4. **Koppling till utbildningen** — Hur har kurserna förberett dig? Vad saknades?
5. **Slutsats** — Tre lärdomar du tar med dig in i arbetslivet

## Längd och format
Minst 1500 ord. Skriv i Markdown och lämna in som PDF.

## Krav för Godkänt (G)
- [ ] Rapporten täcker alla fem delar ovan
- [ ] Konkreta tekniska exempel finns med
- [ ] Reflektion kring yrkesmässig utveckling är genomtänkt

## Krav för Väl Godkänt (VG)
- [ ] Djupgående teknisk analys med jämförelser och egna slutsatser
- [ ] Kopplingen till utbildningen är nyanserad och kritisk
- [ ] Rapporten visar professionell skrivkompetens
