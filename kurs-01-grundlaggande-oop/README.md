# C# Programmering — Kursmaterial

Välkommen! Här hittar du allt kursmaterial organiserat per ämnesmodul.
Nytt material publiceras löpande under kursens gång.

| # | Modul | Innehåll |

| 01 | [Verktyg och Git](01_verktyg_och_git/) | Installation, versionshantering, Git Bash |

## Hur du arbetar med materialet

1. Läs README i varje modul — där står vad du ska kunna
2. Gå igenom föreläsningsslides i `lectures/`
3. Lös övningarna i `exercises/` — varje övning har exempeloutput
4. Lämna in uppgiften i `assignment/` via Google Classroom

## Inlämningar

- Forka startrepot som länkas i uppgiftsbeskrivningen
- Lämna in länken till din fork i Google Classroom
- Deadline står i uppgiften — commits efter deadline räknas inte
