# Vecka 1 — Verktyg och Git

**Tema:** Installation, versionshantering och Git Bash
**Ingen inlämning denna vecka**

## Vad du ska kunna när veckan är slut

- Git installerat och konfigurerat med SSH
- Git Bash är din terminal — du vet grundkommandona
- Du kan klona ett repo, göra ändringar, committa och pusha
- GitHub-konto skapat och kopplat till Git
