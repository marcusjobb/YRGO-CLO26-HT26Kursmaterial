# Modul 4 — Metoder

**Tema:** Metoder, parametrar, returvärden
**Inlämning:** Ingen inlämning

## Vad du ska kunna när modulen är klar

- Skriva `void`-metoder som utför en uppgift utan att returnera ett värde
- Skriva metoder med returvärde och rätt returtyp
- Använda parametrar för att skicka data till en metod
- Anropa metoder från `Main()`
- Förstå DRY-principen (Don't Repeat Yourself) och hur metoder minskar upprepning
