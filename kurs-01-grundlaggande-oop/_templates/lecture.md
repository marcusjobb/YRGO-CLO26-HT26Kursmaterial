## Rubrik

Utförlig förklaring av konceptet. Skriv som om den studerande läser detta
utan att ha varit på lektionen.

```csharp
// Kodexempel med förklaring — svenska kommentarer

```

Förklara vad som händer i koden, rad för rad om det behövs.

---

### Gammal stil → Modern stil

Visa alltid båda. Studerande möter gammal kod i verkligheten.

**Gammal stil:**
```csharp
// Klassisk syntax — fortfarande vanlig i äldre kodbaser
```

**Modern stil (C# X):**
```csharp
// Kortare, men gör exakt samma sak
// Förstå den gamla stilen → den nya är självklar
```
