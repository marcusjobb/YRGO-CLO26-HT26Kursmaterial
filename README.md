## Hur du arbetar med materialet

1. Öppna README i varje modul — där står vad du ska kunna efter veckan
2. Gå igenom föreläsningsslides i `lectures/`
3. Lös övningarna i `exercises/` — varje övning har förväntad output
4. Lämna in via Google Classroom (forka startrepot som länkas i uppgiften)

## Inlämningar

- Forka startrepot som länkas i uppgiftsbeskrivningen
- Lämna in länken till din fork i Google Classroom
