# Programmeringstermer — Kanban och regex

- **Kanban:** Ett sätt att se arbetet som kort som rör sig från vänster till höger över en tavla.
- **Backlog:** Uppgifter som ska göras, men som inte är startade.
- **WIP (Work In Progress):** Uppgifter som pågår just nu. Begränsa antalet, så att flaskhalsar syns.
- **Working:** Kolumnen för det som pågår. Samma sak som WIP på tavlan.
- **Test:** Uppgifter som är klara men ska kontrolleras.
- **Done:** Uppgifter som är klara och godkända.
- **Regex (regular expression, regulärt uttryck):** Ett kort mönster som beskriver en typ av text, till exempel ett postnummer.
- **Grupp (regex):** En del av mönstret inom parentes, som kan hämtas ut separat.
- **Ankare (`^` och `$`):** Mönstret måste matcha från början till slut, annars kan det hitta en del av en längre text.
