# GitHub Student Developer Pack – så verifierar du dig som YRGO-student

Som student kan du få gratis tillgång till verktyg via **GitHub Student Developer Pack** (bland annat GitHub Copilot för studenter). För att få det måste GitHub bekräfta att du är student.

## Varför räcker inte skolmejlen?

Din e-postadress (`@skola.goteborg.se`) delas av många skolor i Göteborgs Stad, inte bara YRGO. Därför kan GitHub inte se enbart på domänen att du går hos oss, och du kan behöva skicka in ett extra underlag. Det är normalt och betyder inte att något är fel.

## Så gör du

1. Gå till <https://education.github.com/pack> och ansök med ditt GitHub-konto.
2. Lägg till din skolmejl i dina GitHub-inställningar och verifiera den.
3. Fyll i skolans namn (YRGO) och följ stegen i ansökan.
4. Om GitHub ber om dokumentation, ladda upp ett underlag enligt nedan.

## Vad ska underlaget visa?

Dokumentet ska tydligt visa **fyra saker**:

- ditt **namn**
- **YRGO** (skolans namn)
- att du är **student just nu** (aktuell registrering)
- ett **synligt datum**

**Exempel på underlag som brukar fungera:**

- studieintyg eller registreringsintyg
- aktuellt schema eller kursöversikt med ditt namn
- tidsstämplad skärmbild från studentportalen
- intyg på skolans brevpapper

**Rangordning – börja högst upp:**

1. Studieintyg eller registreringsintyg från YRGO
2. Tidsstämplad skärmbild från studentportalen (namn, utbildning, aktuell termin)
3. Intyg på skolans brevpapper som säger att du är registrerad just nu
4. Schema eller studieutdrag, om det tydligt visar namn och datum
5. Studiemedelsbesked från CSN, **om** det tydligt visar att du studerar nu. GitHub nämner inte CSN i sin lista över godkända underlag, men flera studenter har fått det godkänt. Använd det som reserv, inte som förstahandsval.

> **Om dokumentet har YRGO:s logga:** det är helt okej. YRGO är en del av Göteborgs Stad, så domänen och skolans namn hör ihop. Det viktiga är att dokumentet visar att *du* är student *nu*.

## Tips för att lyckas

- **Tydligt och läsbart.** Ta hela dokumentet, inte ett utsnitt, och se till att datumet syns.
- **Aktuellt.** Underlaget ska vara daterat inom innevarande termin.
- **Stavning.** Namnet i underlaget ska stämma med namnet på ditt GitHub-konto/din profil.

## Testa själv: ladda upp det du redan har

Du behöver inte vänta på ett särskilt intyg. Ladda upp det du har och se om det går igenom, till exempel:

- **studiemedelsbesked från CSN**
- **ett annat studentintyg** du fått, till exempel via **Mecenat** eller liknande studentrabatt-tjänster
- studieintyg eller portalbild från YRGO

Ingen av dessa är en garanti, och GitHub listar inte CSN eller Mecenat som godkända underlag. Men det kostar ingenting att prova, och flera har fått sådant godkänt. Gäller något av dem **just nu** och visar **namn, datum och att du studerar** kan det räcka.

**Vad som måste synas, oavsett dokument:**

1. ditt **namn**
2. **skolans namn** (YRGO), eller att du studerar
3. att du är **student nu** (aktuell termin eller registrering)
4. ett **datum**
5. **läsbart**: hel sida, skarp bild, inga avklippta hörn

Får du avslag: läs meddelandet och ansök igen med ett annat eller tydligare underlag, **inte samma dokument igen**.

## Om GitHub vill ha en bild med kameran

Ibland ber GitHub dig fota underlaget direkt med webbkameran eller mobilen i stället för att ladda upp en fil. Då gäller det att allt viktigt syns **på en gång** i bild.

Tips från en student på Reddit som blev godkänd inom några minuter (ett tips från communityt, inte från GitHub):

- **Vik pappret** så att namn, datum, skolans namn/logga och eventuellt studentnummer syns samtidigt.
- **Håll det nära kameran.** Det får gärna vara lite suddigt, bara man kan urskilja texten.
- **Använd mobilens framkamera.** Att bilden är spegelvänd spelar ingen roll, det justeras.
- **Gör flera försök.** Det tog två försök tills det såg hyfsat igenkännbart ut.
- Åtkomsten kan ta upp till **72 timmar** att låsas upp efter godkännande.

Poängen är att granskningen verkar leta efter nyckeluppgifter: **namn, datum, skola och helst logga**. Därför är ett intyg på skolans brevpapper med YRGO-loggan ett bra underlag även här.

Använd bara ditt **riktiga** underlag. Det som funkar är att visa det tydligt, inte att ändra något.

## Om du får avslag

Det händer, och det går att göra om:

1. Läs avslagsmeddelandet. Det brukar säga vad som saknades.
2. Ansök igen med ett **tydligare eller kompletterande** underlag. Skicka inte exakt samma dokument igen.
3. Fastnar du fortfarande: kontakta [GitHub Education Support](https://support.github.com/contact/education) eller säg till din lärare.

## Ska skolan göra ett intyg?

Det mest robusta är ett intyg från YRGO som innehåller:

- ditt fullständiga namn
- att du för närvarande är registrerad student vid YRGO
- utbildning eller program
- dagens datum
- att YRGO är utbildningsverksamheten, även om e-postdomänen hanteras inom Göteborgs Stads gemensamma miljö

## Fastnar du?

Hör av dig till din lärare. Vi kan hjälpa till att få fram ett intyg på skolans brevpapper som visar att du är registrerad på YRGO, att YRGO är en del av Göteborgs Stad och att studenterna delar e-postmiljö.

## Integritet

Ladda bara upp ditt underlag direkt till GitHub, inte i klassens repo eller i chatten. Intyg och skärmbilder kan innehålla personuppgifter (till exempel personnummer). **Dölj det som inte behövs** innan du laddar upp, men låt namn, skola, status och datum synas.
